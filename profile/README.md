# Data Science Basics (BIOS 512)

This course teaches the basics of data science with code. We write code by hand first, then learn to pair with AI coding agents.
The primary text is [Hello Data Science](https://hellodata.science/). Topics covered in this course include:
- Data visualization with ggplot2, including scales and themes
- Data wrangling, data types, joining and pivoting
- Reproducible environments with GitHub Codespaces and pixi
- Pairing with AI coding agents
- Regression, model basics, and marginal effects
